# VGEA Conference Platform

Dynamic conference management ecosystem for the Vietnam Green Energy Association (VGEA), including:

- Public Zalo Mini App
- Administration Portal at `https://hoithao-hiephoi.vkesys.com`
- Shared backend APIs
- PostgreSQL data platform
- Registration, check-in, reporting and CMS modules

## Infrastructure targets

- Administration/API server: `192.168.40.94:3003`
- Public administration domain: `https://hoithao-hiephoi.vkesys.com`

All environment-specific values must be provided through environment variables. No IP address, domain, secret or credential may be hardcoded in application source code.
